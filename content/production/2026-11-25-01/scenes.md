## عناصر مصمَّمة بنفس قواعد الحزمة (X01، 2026-11-21) — مسجّلة في `studio/shortcuts/ELEMENTS.md`
- **`secscreen` شاشة الأمان (Ctrl + Alt + Delete):** خلفية كحلية #1D2C48 ← #263E6B، خيارات نص Inter أبيض: Lock / Switch user / Sign out / ··· / Task Manager + Cancel. `times` تظلل كل سطر بكبسولة بيضاء شفافة وشريط أزرق فاتح، `show_at` يلوّن Task Manager بأزرق الشعار، `pick_at` المؤشر ينقر مع حلقة. **بدون شعار Windows/Microsoft وبدون صورة حساب/أفاتار.**
- **`secmini`:** نفس الشاشة مصغّرة ورمادية على الشاشة الثانية، وخط شطب أحمر يرتسم عند `at` مع وميض أحمر خفيف (بأسلوب E13).
- **`tmopen` مدير المهام:** نافذة "Task Manager" نص فقط (Processes، Name/CPU/Memory، صفوف Browser/Game/Updater/Chat/Notes) وأشرطة زينة **بدون أرقام**، شريط جانبي بمربعات مجردة، تنفتح بتكبير مطاطي وتوهج أزرق عند `at`. ما تعرض أي ميزة داخل البرنامج.
- **`steps` عداد الخطوات:** `two` = دائرتين 1 ← 2 (بترتيب القراءة العربي) و"خطوتين"، و`at` يلوّن الدائرة 2 بأزرق الشعار مع حلقة + "خطوة زيادة"؛ `one` = دائرة 1 زرقاء مع علامة صح + "خطوة وحدة".
