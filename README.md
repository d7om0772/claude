# قوالب مونتاج بضغطة زر

قوالب فيديو جاهزة مبنية على [Remotion](https://remotion.dev). المستخدم يختار
قالباً، يعبّي تفاصيله (ألوان، شعار، نص، وسائط، صوت + SRT)، ويحصل على فيديو.
دور المحرّر — بشراً كان أو نموذجاً — **تعديل القالب لا إنشاؤه من الصفر**.

## التشغيل

```bash
npm install
npm run studio     # استوديو المعاينة الحيّة على المتصفح
npm run typecheck
```

الرندر:

```bash
npx remotion render paper-card-kinetic-line out/video.mp4 --props=examples/props.json
```

## عقد القالب

كل قالب مجلد مستقل تحت `src/templates/<id>/` فيه أربعة ملفات، ولا شيء غيرها:

| الملف | الدور |
|---|---|
| `Template.tsx` | المكوّن — التصميم والحركة. **صفر قيم ثابتة**: كل شيء يصل عبر props |
| `schema.ts` | zod schema + `defaultProps`. منه تتولّد واجهة التخصيص تلقائياً |
| `template.json` | ميتاداتا شاشة الاختيار: الاسم، المقاس، المدة، الوسوم |
| `README.md` | خريطة الطبقات، جدول التايم لاين، الثابت مقابل المتغيّر، حدود المحتوى |

الاستثناء الوحيد من الاستقلال: **الخط**. تحميله في `src/lib/fonts.ts` وقواعد
جمالياته في `src/lib/thmanyah-aesthetics.ts`. الخط أصل على مستوى المشروع لا
على مستوى القالب، وعزله يمنع تكرار `delayRender` وتسجيل نفس `FontFace` مرتين.

**إضافة قالب جديد = مجلد جديد + سطر واحد في `src/lib/registry.ts`.**
السجلّ يرفض المعرّفات المكرّرة عند التحميل، لأن معرّفين متطابقين يعنيان
Composition واحداً يطغى على الآخر بصمت فيختفي قالب كامل بلا رسالة خطأ. لا `Root.tsx`
ولا أي ملف آخر يحتاج تعديلاً — الـ Compositions تتولّد من السجلّ.

## القوالب الحالية

| المعرّف | الاسم | المقاس | الوصف |
|---|---|---|---|
| `paper-card-kinetic-line` | الكرت الورقي — السطر الزاحف | ١٠٨٠×١٩٢٠ | سطر عربي ضخم يزحف بمحطة وقوف لكل كلمة، ثم سطر صغير يُبنى كلمة كلمة |
| `paper-karaoke-captions` | كابشن كاريوكي ورقي | ١٠٨٠×١٩٢٠ | كابشن كلمة-بكلمة، النشطة Black داكنة والسابقة Medium أفتح |
| `card-stretch-reveal` | كشف بالتمدّد داخل الكرت | ١٠٨٠×١٩٢٠ | مقطع ينبطح إلى شريط رفيع ثم ينفتح عمودياً في ربع ثانية |
| `thmanyah-word-reveal-vertical` | كشف الكلمات — عمودي | ١٠٨٠×١٩٢٠ | ترجمة تظهر كلمة بعد كلمة وتتراكم داخل بطاقة وسائط |
| `paper-card` | لقطة البطاقة الورقية | ١٠٨٠×١٩٢٠ | بطاقة تصعد من أسفل الإطار، ثم يُقطع محتواها إلى فيديو في نفس الإحداثيات |

## الصوت المرجعي و SRT

القالب **لا يعرف شيئاً عن SRT**. يستقبل مصفوفة `{ text, startMs, endMs }` جاهزة،
والتحويل كله يحصل خارجه في `src/lib/srt.ts` — فيبقى القالب نقياً ويشتغل مع أي
مصدر كابشن (SRT، VTT، تفريغ آلي).

```bash
npm run srt -- examples/sample.srt                      # يطبع الـ JSON
npm run srt -- examples/sample.srt out.json             # يكتبه في ملف
npm run srt -- examples/sample.srt --props props.json   # يحقنه في ملف props
```

المحوّل يتعامل مع: BOM، نهايات CRLF، رقم المقطع المفقود، النقطة بدل الفاصلة في
الطابع الزمني، النص متعدد الأسطر، وسوم التنسيق `<i>`، إحداثيات الموضع، وتداخل
المقاطع (يُقصّ تلقائياً حتى لا يختفي مقطع بلا سبب ظاهر).

تفصيل مهم: `paper-card-kinetic-line` يتوقع كابشن **على مستوى الجملة**، بينما
`paper-karaoke-captions` و `thmanyah-word-reveal-vertical` يتوقعانه **على مستوى
الكلمة** (كل مقطع = كلمة واحدة).
المحوّل يخدم الحالتين — الفرق في تقطيع ملف SRT نفسه.

**المدة تُشتقّ من المحتوى** عبر `calculateMetadata`: من طول ملف الصوت إن وُجد،
وإلا من آخر كابشن، وإلا `fallbackDurationInFrames`.

## جماليات خط ثمانية

كل القوالب تستعمل خط ثمانية سيرف ديسبلاي، بوزنيه المتاحين فقط:
**Black‏ 900** للتأكيد و**Medium‏ 500** لما دونه. لا يوجد Bold في العائلة،
واستعماله لو وُجد يضعّف التباين الذي تقوم عليه هذه القوالب.

خاصية `salt` تعطي أشكالاً ممتدة لحروف نهاية الكلمة. استخراج جدول GSUB من ملف
الخط يعطي **١٥ حرفاً** لها بديل: `ئ ب ت ث س ش ص ض ف ق ك م ن ى ي`.

دليل ثمانية يضع ثلاثة قيود على استعمالها، وهي مطبَّقة في
`src/lib/thmanyah-aesthetics.ts` **كقواعد تُنفَّذ لا كتوصيات مكتوبة**:

| القاعدة | التنفيذ |
|---|---|
| لا تُستخدم في النصوص الطويلة | أكثر من ٨ كلمات ⇒ تُلغى كلياً |
| لا تُستخدم في كلمتين متجاورتين | تُسقَط الثانية من كل زوج متجاور |
| لا تُستخدم بكثرة في الجملة | سقف: واحدة لكل أربع كلمات، قابل للضبط عبر `maxPerWords` |
| — | تُسقَط الكلمات التي لا بديل ممتد لحرفها الأخير |

الدليل يقول «بكثرة» بلا رقم، والقوالب تقرؤها بكثافات مختلفة — قالب الكاريوكي
واحدة لكل ستّ كلمات، وقالب كشف الكلمات واحدة لكل سطر. لذلك الكثافة افتراضٌ
قابل للتجاوز عبر `maxPerWords`، بينما التجاور وغياب البديل قاعدتان صارمتان.

فالمستخدم يطلب ما يشاء، والقالب لا ينفّذ إلا ما يوافق الدليل. النصوص الطويلة
(الثانوي، الكابشن) تُمنع عليها الأحرف المرسلة صراحةً في كل القوالب.

## الخطوط

خط ثمانية Serif Display — **عائلة واحدة بوزنين**: Black‏ (900) للسطر الضخم،
Medium‏ (500) للسطر الصغير والكابشن. الأصل `.otf` ومحوّل إلى `woff2`.

الملفات غير مرفوعة في المستودع (مستثناة في `.gitignore` احتراماً لرخصة ثمانية
التي تمنع إعادة الاستضافة العلنية). راجع `public/fonts/README.md` — بدونها
القالب **يشتغل** لكن بخط بديل، مع تحذير واضح في السجل، والضبط يختلف عن التصميم
الأصلي لأن قياسات `measureText` تتغيّر فتنزاح محطات الوقوف.
