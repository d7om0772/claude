# 🎙️ صوتك — Sawtak

تطبيق ويب يحوّل أي نص عربي إلى **تعليق صوتي احترافي** باستخدام نماذج **Gemini TTS**، مع تحكّم كامل بأسلوب الأداء الصوتي.

الأسلوب الافتراضي هو صوت **شاب سعودي حماسي** بطبقة متوسطة وإيقاع سريع وحيوي بنبرة مقدّم بودكاست إعلاني — جاهز مباشرة للإعلانات والريلز والبودكاست.

---

## ✨ المميزات

| | |
|---|---|
| 🔥 **أساليب جاهزة** | سعودي حماسي، هادئ ودافئ، إخباري رسمي، قصصي مشوّق — أو اكتب أسلوبك الخاص |
| 🎤 **٣٠ صوتاً** | مع وصف عربي لكل صوت وبحث فوري |
| ⚡ **نموذجان مجانيان** | `Flash 2.5` و `Flash 3.1` — كلاهما يعمل على الطبقة المجانية |
| 🌊 **مؤثر موجي حي** | يتراقص مع الصوت أثناء التشغيل |
| ⬇️ **تحميل WAV** | ملف جاهز للاستخدام في المونتاج |
| 🕘 **سجل الجلسة** | آخر ٦ عمليات توليد بضغطة واحدة |
| 🔒 **المفتاح آمن** | يبقى على الخادم ولا يصل للمتصفح أبداً |
| 📦 **صفر اعتماديات** | Node.js فقط — لا `npm install` ولا خطوة بناء |

---

## 🚀 التشغيل

```bash
# 1) أضف مفتاح Gemini
cp .env.example .env
#    ثم افتح .env وضع مفتاحك من https://aistudio.google.com/apikey

# 2) شغّل
npm start
```

ثم افتح: **http://localhost:3000**

> يمكنك أيضاً تمرير المفتاح كمتغيّر بيئة مباشرة:
> `GEMINI_API_KEY=xxx npm start`

**المتطلبات:** Node.js 18 أو أحدث فقط.

> 💡 **يعمل على الطبقة المجانية من Gemini بالكامل.** النموذجان المتاحان
> (`gemini-2.5-flash-preview-tts` و `gemini-3.1-flash-tts-preview`) مجانيان.
> نموذج `pro-tts` مستبعد عمداً لأنه يتطلب تفعيل الفوترة ويرجع `429` دائماً
> على الحساب المجاني. لو تجاوزت حصة الدقيقة، ينتظر التطبيق ويعرض لك رسالة واضحة.

## 🧠 كيف يشتغل؟

تعليمات الأداء الصوتي تُرسل لجيمناي **قبل** النص نفسه، وهي اللي تتحكم بالنبرة والإيقاع والطاقة:

```
اقرأ النص التالي بصوت شاب سعودي حماسي، طبقة صوت متوسطة، إيقاع سريع وحيوي
بأسلوب مقدم بودكاست إعلاني، مع تلوين واضح في النبرة: صعود حماسي في بداية
الجمل وتشويق قبل النقاط المهمة، ووقفات قصيرة جداً بين الأفكار، وطاقة عالية
ثابتة من أول كلمة لآخر كلمة. النص:

<النص المُدخل هنا>
```

يُرجع Gemini صوتاً خاماً بصيغة PCM 16-bit / 24kHz، والخادم يغلّفه برأس WAV
حتى يشتغل مباشرة في المتصفح وعند التحميل.

## 📡 الواجهة البرمجية

### `POST /api/tts`

```jsonc
{
  "text":  "النص المراد تحويله",          // مطلوب — 5000 حرف كحد أقصى
  "style": "تعليمات الأداء الصوتي",        // اختياري
  "voice": "Puck",                        // اختياري — الافتراضي Puck
  "model": "gemini-2.5-flash-preview-tts" // أو gemini-3.1-flash-tts-preview
}
```

**الاستجابة:**

```jsonc
{
  "audio": "<WAV بترميز base64>",
  "mimeType": "audio/wav",
  "sampleRate": 24000,
  "bytes": 398010,
  "durationSeconds": 8.29,
  "model": "gemini-2.5-flash-preview-tts",
  "voice": "Puck"
}
```

عند الخطأ يرجع `{ "error": "رسالة بالعربية" }` مع كود HTTP مناسب.

### `GET /api/health`

```json
{ "ok": true, "hasKey": true, "maxChars": 5000 }
```

## ☁️ النشر السحابي

المشروع جاهز للنشر كما هو — بدون اعتماديات وبدون خطوة بناء.

### Render (مجاني، موصى به)

1. سجّل في [render.com](https://render.com) بحساب GitHub.
2. `New` ← `Blueprint` ← اختر مستودع `claude` والفرع المطلوب.
3. سيقرأ Render ملف `render.yaml` تلقائياً.
4. أضف متغيّر البيئة `GEMINI_API_KEY` بقيمة مفتاحك ← `Apply`.

> ⏳ الخطة المجانية توقف الخدمة بعد ١٥ دقيقة خمول، فأول طلب بعدها يستغرق
> ٣٠–٥٠ ثانية حتى تُشغَّل من جديد. الطلبات التالية سريعة.

### أي منصة أخرى

يكفي أن تدعم Node.js 18+ وتضبط متغيّرين:

| المتغيّر | القيمة |
|---|---|
| `GEMINI_API_KEY` | مفتاحك من Google AI Studio |
| `PORT` | تضبطه المنصة عادةً بنفسها |

وأمر التشغيل: `npm start`

> 🔐 **تنبيه:** بعد النشر يصبح الرابط عاماً، وأي شخص يفتحه يستهلك من حصة
> مفتاحك المجانية. لا تنشر الرابط علناً، أو أضف حماية بكلمة مرور.
