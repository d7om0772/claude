# 🎬 مستخرج الفريمات (Frame Picker)

أداة ويب تعمل **بالكامل داخل المتصفح**: ترفع فيديو → تستعرض فريماته كشبكة صور →
تحدّد الفريمات التي تريدها → تصدّرها كصور (أو ملف ZIP).
**فريم منتصف المقطع معلّم بوضوح** بلون ذهبي وشريط فاصل في الشبكة وعلامة على الخط الزمني.

> لا يُرفع الفيديو إلى أي خادم. كل شيء يتم محليًا عبر `<video>` + `<canvas>`.

## المزايا

- **رفع بالسحب والإفلات** أو الاختيار اليدوي (MP4 / WebM / MOV … حسب دعم المتصفح).
- **اكتشاف تلقائي لمعدل الفريمات** عبر `requestVideoFrameCallback`، مع زر
  «كل الفريمات» لاستخراج المقطع بمعدله الأصلي.
- **تحكم في كثافة الاستخراج** (فريم/ثانية) وحدّ أقصى لحماية الذاكرة.
- **علامة منتصف المقطع**: إطار ذهبي + شريط `⏺ فريم المنتصف` + فاصل في الشبكة +
  علامة ذهبية على الخط الزمني + زر «الانتقال للمنتصف»، ويُحدَّد تلقائيًا بعد الاستخراج.
- **تحديد مرن**: نقرة للتبديل، `Shift + نقرة` لتحديد مدى، تحديد الكل/عكس التحديد.
- **عارض مكبّر** بالدقة الأصلية مع التنقل بالأسهم و`Space` للتحديد و`Esc` للإغلاق.
- **تصدير بالدقة الأصلية للفيديو** (وليس دقة المصغّرة) بصيغة PNG / JPEG / WebP.
- **ملف `frames.json`** اختياري داخل الـ ZIP يحتوي رقم كل فريم وتوقيته وهل هو فريم المنتصف.

## طريقة العمل

| الخطوة | التنفيذ |
|---|---|
| قراءة الملف | `URL.createObjectURL(file)` على عنصر `<video>` مخفي |
| قياس FPS | تشغيل لحظي + وسيط الفروق في `mediaTime` من `requestVideoFrameCallback` |
| استخراج فريم | `video.currentTime = t` → انتظار `seeked` → `ctx.drawImage(video, …)` |
| المصغّرات | JPEG بجودة 0.82 كـ `Blob` + `objectURL` (توفير ذاكرة) |
| التصدير | إعادة `seek` ورسم بالدقة الأصلية ثم `canvas.toBlob` |
| التحزيم | JSZip مع شريط تقدم |

عمليات الوصول إلى عنصر الفيديو مُسلسَلة عبر قفل وعود (promise chain) حتى لا تتداخل
عمليات الـ seek بين الاستخراج والمعاينة والتصدير.

## التشغيل محليًا

```bash
python3 -m http.server 8080   # ثم افتح http://localhost:8080
```

## النشر

موقع ثابت — `publish = "."` في `netlify.toml`، بدون خطوة بناء.

## الملفات

```
index.html    الواجهة
styles.css    التصميم (داكن، RTL)
app.js        منطق الاستخراج والتحديد والتصدير
netlify.toml  إعدادات النشر
```
