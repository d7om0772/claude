# نظام «الاستعارة الشارحة»: فهرس

| الملف | وش فيه | متى تستخدمه |
|---|---|---|
| `style-guide.md` | الأسلوب بالتفصيل: البنية، والإيقاع، والحركة، والنصوص، والألوان، والصوت، والثابت والمتغير | اقرأه مرة كاملة، وارجع له كمرجع |
| `template.md` | قالب فارغ بالثواني (30/36/45/60ث) + ورقة الاستعارة + الكابشن + المؤثرات + العناصر | انسخه لكل فيديو جديد |
| `prompt.md` | برومبت جاهز لأي ذكاء اصطناعي (حزمة إنتاج كاملة) + برومبت تحريك + برومبت مراجعة | لما تبي تولّد فيديو جديد بسرعة |
| `element-prompts.md` | أوامر توليد العناصر على kie.ai (GPT Image 2) بالإعدادات | بعد ما تثبّت الاستعارة |
| `checklist.md` | قائمة تحقق قبل النشر | آخر خطوة قبل النشر |

**الترتيب المقترح:** `prompt.md` (أو `template.md` يدوياً) ← `element-prompts.md` ← المونتاج حسب `style-guide.md` ← `checklist.md`.
