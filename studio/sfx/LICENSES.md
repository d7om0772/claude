# رخص المؤثرات الصوتية — studio/sfx

كل المؤثرات هنا **مولّدة بالكود** داخل المستودع (`generate_sfx.py`، numpy، بذرة ثابتة) — ما فيها أي تسجيل أو عينة من طرف ثالث.
الرخصة: **CC0 / إنتاج داخلي**. ما تحتاج إسناد، لكن نذكرها في `credits.md` لكل فيديو للشفافية.

| الملف | الوصف | الاستخدام |
|---|---|---|
| whoosh.wav | مرور هوائي ناعم | انتقال كاميرا، بطاقة كبيرة |
| swoosh_up.wav | مرور صاعد قصير | ظهور الهوك/النص الكبير |
| pop.wav | فرقعة خفيفة | ظهور بطاقة/ملصق |
| click.wav | نقرة زر | ضغط زر في الاختصارات |
| thud.wav | ارتطام منخفض | نزول قطعة في الكيس |
| snap.wav | تثبيت (نقرتين) | قطعة/كيبل انشبك |
| tick.wav | تكة عداد | عداد أرقام |
| ding.wav | نغمة وحدة صافية | الختام، رقم نهائي |
| error.wav | طنين منخفض | حالة المشكلة |
| success.wav | نغمة إيجابية وحدة | حالة الحل |
| rise.wav | ضجيج صاعد | قبل كشف نتيجة |

**لا موسيقى ولا ألحان:** كل مؤثر نغمة وحدة أو ضجيج مشكّل، أقل من ثانية.
حزم الستايل الأصلية (لما تتثبت) ممكن تذكر مؤثرات بأسماء محددة: لو مصدرها خارجي (freesound، Pixabay...) نزّلها هنا مع ملف رخصة لكل وحدة وسطر في هذا الجدول، وأي مؤثر CC BY لازم سطر إسناد في كابشن المنشور.
