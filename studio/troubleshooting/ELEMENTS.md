# عناصر قالب `troubleshooting` — حزمة `14_desk_pc_red_green`

> **المرجع البصري الملزم:** `brand/styles/troubleshooting/` (01_prompt.md، 02_elements، 04_design_style، 05_colors، 03_preview.mp4).
> هذا الملف يشرح **كيف تستدعي** كل عنصر في `scene_draft.json`. جدول اختيار العناصر (B1–B15) في `01_prompt.md`.

**حقول المشهد:** `header.label` ("المشاكل وحلولها") · `header.dots` (عدد الخطوات) · `initial_state` ("problem") · `hook.title: {main:"مؤشر الماوس !!اختفى؟!!", desc}` · `idle_screen` · `camera.variant` 0–3.
**الحالة اللونية:** إضاءة RGB والشارات **حمراء** (`#FF3347`) وقت المشكلة، و**خضراء** (`#22D36A`) لحظة الحل — آخر حالة بدأت هي اللي تغلب.
**الكاميرا:** لقطة افتراضية لكل عنصر؛ غيّرها بـ `params.cam`: `wide`, `monitor`, `desk`, `mouse`, `case`, `caseTop`, `laptop`.
**تلقائي:** الختام E17 ("المشاكل وحلولها · تيربو")، والمؤثرات (خطأ للمشكلة، نغمة الحل عند `fix_at`، ضغطات...).

| العنصر | params | ملاحظات |
|---|---|---|
| **E01** المشهد الواسع | — | يتركب بنطّات، الإضاءة حمراء |
| **E02** المؤشر المختفي | — | دائرة حمراء متقطعة "?" على الشاشة. العنوان بكلمة حمراء `!!…!!` |
| **E03** شارة الخطوة ونقاط التقدم | `index` · `title` · `desc` · `desc_at` · `fix_at` (كلمة الحل) · اختياري `keys`, `key_times`, `keys_ok_at` | الشارة "الخطوة N" حمراء ونقطتها حمراء، وعند `fix_at` تقلب أخضر مع ✓ ونبضة |
| **E04** بطن الماوس والبطارية | `swap_at` | الماوس ينقلب، البطارية القديمة تطير والجديدة تنزل |
| **E05** أيقونة الشحن | — | دائرة خضراء فيها صاعقة جنب الماوس |
| **E06** زر OFF / ON | `at` | ينزلق من OFF الأحمر لـ ON الأخضر |
| **E07** المنفذ الأمامي | — | الوصلة تطلع من المنفذ الأمامي فوق الكيس مع وميض أحمر |
| **E08** ظهر الكيس والمنفذ الخلفي | `from`: `usb_front` / `mobo_hdmi` · `to`: `usb_rear` / `gpu_out` · `plug_at` | الكيس يلف 90° ويبين ظهره (منافذ البوردة فوق + منافذ كرت الشاشة تحت)، والوصلة تنتقل وتتوهج أخضر. **`mobo_hdmi → gpu_out` = كيبل الشاشة في المكان الغلط** |
| **E09** التاتش باد المقفول | `until` | لابتوب بدل الكيبورد، والتاتش باد عليه X أحمر |

| **E11** Fn + الزر = تشغيل | `key` · `key_times` · `fix_at` | الأزرار خضراء، التاتش باد ✓، المؤشر يرجع |
| **E12** شاشة Ctrl + Alt + Delete | `key_times` · `items` | الأزرار تنضغط بالترتيب وتطلع شاشة الخيارات |
| **E13** رجوع المؤشر | `key_at` (Esc) | حلقة خضراء و✓ |
| **E14** الماوس على جهاز ثاني | — | لابتوب صغير قدام الكيس والماوس ينط عليه |
| **E15** علامات الاستفهام | — | "؟" حمراء فوق الكيس وفوق الماوس |
| **E16** فقاعة التعليق | `text` · `title` ("واجهتك مشكلة ثانية؟") · `desc` | |
| **E17** الختام | — | تلقائي |
| **X01** عرض شاشة إضافي (بنفس الأسلوب) | `mode`: `no_signal` / `display_settings` (`from`,`to`) / `bios_xmp` (`profile`,`speed_off`,`speed_on`) / `temps` (`items:[[الاسم، قبل، بعد]]`) / `startup` (`apps`) / `fan_curve` / `ping` (`bad`,`good`) / `stutter` / `text` / `off` / `desktop` / `input_menu` (`items`,`from`,`to`,`pick_at`: قائمة مدخلات الشاشة، التحديد يقلب أخضر) / `cursor_back` · `state`: `problem`/`fix` · `cam` | لمشاكل ما لها عنصر في الحزمة (الشاشة السوداء، 60Hz، XMP، الحرارة، برامج بدء التشغيل، المراوح، البنق). سجّله في جدول المشاهد كعنصر مصمَّم بنفس قواعد الحزمة |
