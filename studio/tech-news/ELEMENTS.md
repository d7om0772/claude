# tech-news — طريقة استدعاء عناصر حزمة `16_quick_explainer`

المرجع البصري الملزم: `brand/styles/tech-news/01_prompt.md` و`02_elements/elements.md` و`06_style_system_v2/`.
هذا الملف يشرح **كيف تكتب كل عنصر في `scene_draft.json`**. كل عنصر = لقطة تبدأ مع كلمتها، و`end` اختياري (اللقطة تستمر لين اللي بعدها).
التوقيتات: رقم، أو `"w12"` / `"w12.end"`، أو `{"find": "نص", "nth": 1, "edge": "start|end", "shift": 0}`. **أي حقل اسمه `at` أو ينتهي بـ `_at` وقت، وأي حقل `times` / `*_times` قائمة أوقات** — في أي مستوى داخل params.
نص فيه `**كلمة**` = لون الأكسنت (برتقالي) — للكلمة المفتاحية والأرقام المهمة **فقط**. اللاتيني والأرقام تنعزل LTR تلقائياً.

## الحقول العامة للمسودة
```json
{ "id": "2026-11-18-N1", "series": "tech-news", "style": "16_quick_explainer", "hero": "gpu",
  "keywords": ["NVIDIA"],            // كلمات الكابشن اللي تتلوّن بالأكسنت (الأرقام تتلوّن تلقائياً)
  "events": [ ... ], "auto_sfx": true }
```
- `hero`: العنصر البطل للفيديو (يرجع في E14): `gpu` `chip`/`cpu` `ram` `ssd` `monitor` `laptop` `case` `server` (رسومات كبيرة)، أو أي أيقونة من القائمة تحت داخل كرت.
- الكابشن العلوي (E16) تلقائي من `captions.json`: 1–4 كلمات بالسطر (`caption_max_words`)، ويختفي على الكروت النصية (E01، E04، E13، E14).
- الحلقة (E15) تلقائية: `scene_build` يضيف `loop` 0.85ث (آخر لقطة = أول لقطة).

## العناصر
| العنصر | العالم | متى | params |
|---|---|---|---|
| **E01** كرت الهوك | هوية | أول 1.5–2ث (start = 0) | `text` (السطر الأول)، `big` (الرقم/الكلمة الكبيرة، غالباً `**1999**`)، `big_at`، `y` |
| **E02** البطل + ختم الجواب | هوية | جملة الجواب | `hero`، `stamp` (الكلمة الأهم بختم أكسنت)، `stamp_at`، `sub` (سطر تحت)، `sub_at`، `tag` (رقم صغير على البطل مثل 2026)، `tag_at` |
| **E03** وميض معكوس | — | **مرتين بس**: قبل الجسر وقبل عالم الأمثلة | `start` فقط (فريمين × 2) |
| **E04** كرت الجسر | جسر أزرق | جملة الانتقال/"ليش؟" (الوقفة الوحيدة) | `text`، `big` (رقم بالأكسنت) — كل كلمة تطلع مع نطقها |
| **E05** الرف: نظرة عامة | أمثلة (خشب) | تقديم الأمثلة الثلاثة | `plate` (لوحة صغيرة مثل `"NVIDIA · 2026"`)، `slots: [{icon, label, light?, unknown?, at}] ×3` (`light` = صندوق أبيض، `unknown` = مكان منقّط عليه ؟) |
| **E06** كرت المثال | أمثلة | كل مثال | `slot` (0،1،2)، `enter`: `zoom` (أول مثال) / `pan` (0.55ث) / `whip` (الأبعد، 0.42ث + blur)، `name` (96px)، `name_at`، `badges: [{icon, text, at}]` (2–3، أيقونة + كلمتين)، `details` (= حقول E08) |
| **E07** انتقال كاميرا فقط | أمثلة | لو تبي تنتقل بدون كرت | `slot`، `enter` |
| **E08** تفاصيل حية | أمثلة | معلومة زمنية أو غير مؤكدة | `papers_at` (أوراق "؟" تطير)، `calendar: ["2026","2027","2027+","؟"]`، `cal_times` (وقت كل قلبة) |
| **E09** المخطط (الهب) | شرح غامق | "ليش" والعوامل | `center` (مثل "السبب")، `sub` (مثل "حسب التقارير")، `slots_at` (الخانات المنقطة على كلمة "ثلاث/عاملين")، `factors: [{icon, text, at}]` (2–3) |
| **E10** لوحة التكبير | شرح (المخطط يعتم) | إثبات عامل واحد بالحركة | `focus` (رقم العامل)، `mode`: `flow` (افتراضي: `from:{icon,label}` ← `to:{icon,label}` وقطع تتحرك بينهم) أو `bars` (`bars:[{label, value, text, accent?}]`) |
| **E11** وش يعني لك | هوية | تطبيق الخبر على المشاهد | `hero`، `name`، `badge` + `badge_at` (أو `badges`)، `corner_icon` (افتراضي clock) |
| **E12** الساعة الرملية | هوية | انتظار/مدة غير معروفة | `label`، `badges`، `flip_at` (تنقلب)، `stretch_at` (تتمدد مع "يطول") |
| **E13** كرت الـ CTA | هوية | دعوة للتعليق بكلمة وحدة | `top` (افتراضي "اكتب بالتعليقات")، `words: ["الحين","أنتظر"]` (كلمة أو كلمتين بـ «»)، `or`، `sub`، `word_times` (تلقائي من الترجمة) |
| **E14** الختام | هوية | آخر جملة فيها رقم | `top`، `big` (`**الرقم**`)، `bottom`، `hero` (يرجع بانزلاق)، والشعار صغير تحت تلقائياً |
| **X01** لقطة إضافية | هوية | عنصر مو موجود في الحزمة | نفس حقول E11 (`hero`، `name`، `badges`، `corner_icon` اختياري) — سجّله في جدول المشاهد |

### الأيقونات (للشارات والعوامل والرف)
`gpu` `chip`/`cpu` `ram` `ssd` `monitor` `laptop` `case`/`pc` `motherboard` `server` `gamepad` `keyboard` `mouse` `plus` `check` `x` `clock` `calendar` `doc` `question` `bolt` `chart` (صعود) `down` (نزول) `tag`/`price` `cloud` `ai` `lock` `wifi` `download` `globe` `warn` `star` `shield` `battery` `fan` `arrow` `fire` `power` `thermo` `speed`
**كلها جمادات.** لا تضيف أيقونة فيها كائن حي.

## المؤثرات التلقائية (`auto_sfx`)
whoosh (`gs_swipe2`) قبل كل قص بـ 0.15ث · `gs_select_option11` مع الوميض · `gs_punch_gut` (thud) على الجسر وكلمة الـ CTA · `gs_item_pickup4` (pop) للشارات والعوامل والأماكن · `gs_dropping_item` للدبوس · `gs_bump1` للختم · `gs_reflect2` (shimmer) للتوهج · `gs_charging2` (rise) لرسم الخطوط · `gs_swipe_grass2` للانتقال الجانبي · `gs_swipe_grass5` للأوراق والساعة · `gs_selection9_fwd` لقلب التقويم. أي ملف ناقص له بديل مولّد بالكود.
