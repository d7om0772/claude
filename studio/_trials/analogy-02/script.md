# صوّر **الجزء** بس — Win + Shift + S بأسلوب الشرح بالتشبيه

## وش تغيّر عن السكربت الأصلي
- **المعلومات نفسها** من السكربت المعتمد ومراجعه، بدون أي ادعاء جديد. اللي انضاف هو **التشبيه**: قطّاعة البسكوت بدل القص بالسكين (تصوير، مو معلومة).
- الخطوات صارت قالب الأسلوب: مخطط (الشريط + الأشكال الأربعة) ← 3 أمثلة (اسحب ← الحافظة / Ctrl + V / بونص Win + Shift + R).
- انحذف من الأصل: "فيه طريقة أسرع"، وجملة Snipping Tool (#6: التعديل والحفظ) عشان المدة.
- الـ CTA: كلمة تعليق بدون وعد بإرسال شي.

## نص الكابشن (المعروض) ونص التعليق (المنطوق)
الفرق الوحيد: الأزرار. الكابشن يكتبها أزرار (`Win + Shift + S`، `Ctrl + V`، `Win + Shift + R`)، والتعليق ينطقها حسب `brand/voice.md §٣.٤` (Windows و Shift و إس / Control و في / Windows و Shift و آر).

**ملاحظات للمدقق لو بينشر:**
- المصادر تخص **Windows 11**؛ الفيديو ما يكتبها على الشاشة. كابشن المنشور الأصلي يذكر "(Windows 11)" — خلّه.
- زر Win مكتوب نص "Win" بدون شعار ويندوز (قاعدة الشعارات).
- نطق الأزرار: Whisper سمع "ويندوز وشفت واسمع بعض" (= Windows و Shift و إس مع بعض) و"Ctrl و V" — يحتاج سمع بشري.

## وين خالفت التجربةُ دليلَ الأسلوب

| الهوك يطلع كلمة كلمة من شاشة فاضية | الهوك كامل من أول فريم والكلمة المنطوقة تنط | قاعدة الحلقة: الفريم الأول لقطة مكتملة |

| ختام برقم | "تابع تيربو" + أيقونة الشعار | ما نخترع أرقام |
| 60fps | 30fps | معيار تيربو |
| المخطط: مركز وأطراف يمين ويسار | شريط القص فوق والأشكال الأربعة صف تحته | يطابق شكل الشريط الحقيقي (الأشكال جنب بعض) |
