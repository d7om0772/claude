**الاستخدام:** عبّي قسم المدخلات، وانسخ البرومبت كامل لأي ذكاء اصطناعي.
- **أداة نصية:** تطلّع السكربت + جدول اللقطات + الكابشن + المؤثرات + برومبتات الرسومات.
- **أداة كود أو موشن:** أضف "الملحق أ".
- **أداة صور:** "الملحق ب".
- نسخة إنجليزية مختصرة في "الملحق ج".

## البرومبت الرئيسي

```
أنت مخرج ومونتير فيديوهات قصيرة عمودية. اصنع لي فيديو بأسلوب "الشرح السريع"
حسب المدخلات والقواعد. القواعد هي الأسلوب، والمدخلات هي المحتوى.
ممنوع تستخدم تشبيه أو مثال يومي من خارج الموضوع (مثل "تخيّل حنفية...").
ادخل في الموضوع مباشرة.

═══ المدخلات ═══
الموضوع: [ ]
السؤال اللي يبدأ فيه الفيديو: [ ]
الكلمة المفتاحية: [ ]
3 عوامل/أجزاء تشرح "ليش": [ ] / [ ] / [ ]
العامل اللي نكبّر عليه ونشرحه بحركة: [ ]
عالم الأمثلة (خريطة، رف، شاشة، خط زمني...): [ ]
3 أمثلة، ولكل مثال 2–3 معلومات قصيرة: [ ] / [ ] / [ ]
كلمة الـ CTA: [ ]
رقم للختام (بمصدره): [ ]
المصادر المسموحة للمعلومات: [ ]
اللغة واللهجة: [ ]
الألوان (هوية / جسر / شرح / أمثلة / أكسنت): [ ]
المدة: [ 34 ] ثانية

═══ قاعدة ملزمة: بدون صور ذوات الأرواح ═══
ممنوع في أي مشهد: أشخاص أو أي جزء منهم (وجوه، أيادي، أصابع، ظلال)، حيوانات،
طيور، حشرات، شخصيات مرسومة، روبوتات بوجوه، إيموجي لكائنات حية — حتى داخل
لقطات الشاشة والملصقات. المسموح: جمادات، منتجات، خرائط، نباتات، أشكال، نصوص.
الفعل يبان بحركة الشي نفسه أو دبوس أو مسار، مو بيد.

═══ المواصفات ═══
1080×1920 عمودي، 30 أو 60fps. بدون موسيقى: تعليق صوتي + مؤثرات فقط.

═══ البنية (بالترتيب وبالثواني لـ 34 ث) ═══
1) هوك 0–1.5: سؤال 2–4 كلمات، نص فقط على خلفية الهوية، كامل من أول فريم.
2) جواب 1.5–4.2: جملة وحدة + عنصر بطل يدخل بـ punch-in، وعلامة/توهج على الكلمة الأهم.
3) جسر 4.2–5.4: سؤال "ليش...؟" على لون كامل. الوقفة الوحيدة (~0.35 ث صمت بعده).
4) مخطط 5.4–9.5: المركز ثم 3 خانات منقطة على "ثلاث"، وكل عامل يمتلي مع نطقه.
5) تكبير 9.5–13.7: الكاميرا تدخل على عامل واحد، والمخطط يعتم، ولوحة فيها حركة تثبت الكلام.
6) أمثلة 13.7–27: 3 أماكن في عالم واحد. الكاميرا: zoom ← pan ← whip.
   تحت الصورة: اسم المثال كبير + 2–3 شارات (أيقونة + كلمتين) تطلع مع نطقها.
7) CTA 27–29: "اكتب" ← خط ← «الكلمة» بأكبر حجم ← سطر صغير.
8) ختام 29–33: العنصر البطل يرجع + جملة فيها رقم بالأكسنت.
9) حلقة 33–34: آخر ثانية تذوب في أول فريم.

═══ الإيقاع ═══
- تعليق 2–2.2 كلمة/ث، فراغات ≤ 0.25 ث (إلا بعد الجسر).
- حدث بصري كل 0.5–1 ث، وما فيه إطار ثابت أكثر من ثانية.
- كل قص في فراغ بين جملتين، وكل حدث على كلمته.

═══ الحركة ═══
- push-in بطيء على كل شي. ممنوع dissolve و fade بين المشاهد.
- وميض معكوس مرتين بس: قبل الجسر، وقبل عالم الأمثلة.
- pop مع overshoot للعناصر، والخط ينرسم قبل عنصره.

═══ النصوص ═══
- كابشن في شريط علوي (مركزه 16% من الارتفاع)، كبسولة فاتحة، سطر واحد،
  1–5 كلمات، كلمة كلمة مع النطق. كلام أقل = خط أكبر.
- كروت نصية في الوسط. أكسنت واحد للكلمة المفتاحية والأرقام المهمة.
- لا شي مهم فوق 180px ولا تحت 1500px ولا يمين 960px بين 800 و1600.

═══ الألوان ═══
3 عوالم: هوية (فاتح) / شرح (غامق + توهج) / أمثلة (خامة مختلفة). قلب التباين بينها.
عنصر واحد في الوسط، نص فوق، آخر 22% فاضي.

═══ الصوت ═══
بدون موسيقى. مؤثر قصير لكل حدث (whoosh قبل القص بـ 0.15 ث، pop للعناصر،
drop للدبوس، thud للجسر والـ CTA). المؤثرات أخفض من الكلام بـ 10–12 dB.

═══ المطلوب ═══
1. سكربت التعليق كامل، مقسّم على الأجزاء، مع عدد الكلمات والتوقيت.
2. جدول مراجع: كل معلومة ← مصدرها. لو ما لقيت مصدر، احذف المعلومة.
3. جدول لقطات: من–إلى · الصوت · الصورة · الحركة · الانتقال.
4. جدول كابشن، وجدول مؤثرات.
5. برومبت صورة لكل رسمة (بدون نص وبدون كائن حي).
6. مراجعة ذاتية مقابل القواعد.
لا تخترع معلومة. لا تضيف تشبيه. لا موسيقى. لا مقدمة ولا outro.
```

## الملحق أ — لأدوات الكود والموشن

```
ابنِ الفيديو بـ [Remotion / HTML+CSS+JS / After Effects].
- 1080×1920، 30fps. كل حدث مربوط بتوقيت كلمته (word timestamps من التعليق).
- الكابشن: مركز y≈312، كبسولة تكبر مع الكلام، الكلمة: opacity 0→1 و translateY 0.3em→0 خلال 150ms.
- push-in: scale 1.00→1.06 على طول اللقطة. pop: scale 0→1.1→1 خلال 300ms.
- الوميض: invert(1) لمدة إطارين، مرتين، ثم قص.
- عزل العمق: الخلفية opacity→0.25 و blur 7px خلال 300ms.
- الخريطة أو العالم الكبير: حرّك الكاميرا بتغيير viewBox أو background-position،
  مو بـ transform على طبقة أكبر من الشاشة.
- لا تحط filter على مشهد كامل (أبيض وأسود مثلاً): استخدم طبقة فوقه mix-blend-mode.
- الصوت: تعليق + مؤثرات، كل مؤثر انتقال يتقدّم القص بـ 150ms، بدون موسيقى.
```
