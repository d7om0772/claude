# عناصر قالب `shortcuts` — حزمة `13_mini_desk_diorama`

> **المرجع البصري الملزم:** `brand/styles/shortcuts/` (01_prompt.md، 02_elements، 04_design_style، 05_colors، 03_preview.mp4).
> هذا الملف يشرح **كيف تستدعي** كل عنصر في `scene_draft.json`. جدول اختيار العناصر (B1–B15) في `01_prompt.md`.

**حقول المشهد:** `header.label` ("اختصارات ويندوز") · `header.dots` (عدد الاختصارات، افتراضي 5) · `hook.title: {main:"**5** اختصارات", desc:"بتوفر وقتك كل يوم"}` · `camera.variant` 0–3.
**الكاميرا:** كل عنصر له لقطة افتراضية (واسعة / الشاشتين / الرئيسية والكيبورد / شاشة وحدة). تقدر تغيّرها بـ `params.cam`: `wide`, `screens`, `main`, `left`, `right`.
**تلقائي:** الختام E17 (الشعار على الشاشة الرئيسية + "تيربو · اختصارات ويندوز")، والمؤثرات، ونقرة كيبورد لكل `key_times`، ونبضة الكيبل بعد آخر زر في E03.

| العنصر | params | ملاحظات |
|---|---|---|
| **E01** المشهد الافتتاحي | `big` ("5") · `text` ("اختصارات") · `clock` | الغرفة تتركب بنطّات؛ الشاشة الثانية ساعة |
| **E02** الساعة الدوارة | `text` ("وقت") · `spins` (3) · `screen` | للوقت والتوفير |
| **E03** شارة الاختصار وأزراره | `index` (1..) · `label` (افتراضي "الاختصار الأول"...) · `keys:["Win","Shift","S"]` · `key_times:["w5","w7","w9"]` (كلمة كل زر) · `desc` · `desc_at` · `pulse` | الشارة + الأزرار (keycaps) في منطقة العنوان، والزر ينضغط مع نطقه، والنقطة في الهيدر تتفعل. الأزرار في الكيبورد المجسم تنضغط بنفس التوقيت |
| **E04** الكيبورد والأزرار المضغوطة | `keys`, `key_times` (اختياري) | لقطة قريبة للشاشة الرئيسية والكيبورد |
| **E05** نبضة الكيبل | `at` | نقطة ضوء من الكيبورد للشاشة (تلقائية مع E03) |
| **E06** نقل النافذة بين الشاشتين | `title` ("Documents") · `back` | |
| **E07** توهج الشاشتين | — | "لو عندك أكثر من شاشة" |
| **E08** سطح مكتب جديد | `label` ("Desktop 2") | |
| **E09** المؤشر يقفل التبويب | `tabs` | الغلطة |

| **E11** قائمة الإيموجي | `text` | **أشياء ورموز فقط** (قلب، نجمة، صاعقة، شمس، غيمة…) — بدون وجوه أو كائنات حية |
| **E12** تبويب الرموز وإضافة رمز | `text` | |
| **E13** مسح الكلمة كاملة | `text` (الجملة على الشاشة) | آخر كلمة تومض أحمر وتنمسح |

| **E15** شاشة احفظ | `text` · `title` · `desc` | |

| **E17** الختام | — | تلقائي |
| **X01** عرض شاشة إضافي (بنفس الأسلوب) | `mode`: `snip` / `clipboard` (`items`) / `taskmgr` (`rows`) / `snap` / `lock` (`time`) / `text` (`text`,`size`) / `desktop` · `screen` · `cam` | لاختصارات ما لها عنصر في الحزمة (Win+Shift+S، Win+V، Ctrl+Shift+Esc، Win+←/→، Win+L…). سجّله في جدول المشاهد كعنصر مصمَّم بنفس قواعد الحزمة |

**قواعد:** أسماء الأزرار بالإنجليزي على الشاشة (Win, Ctrl, Shift...) — بدون شعار Windows. الكلمة اللي تنضغط معها الزر = `key_times`.
