# عناصر قالب `budget-builds` — حزمة `15_iso_build_drop`

> **المرجع البصري الملزم:** `brand/styles/budget-builds/` (01_prompt.md، 02_elements/elements.md + elements_sheet.jpg، 04_design_style، 05_colors، 03_preview.mp4).
> هذا الملف يشرح **كيف تستدعي** كل عنصر في `scene_draft.json`. جدول اختيار العناصر (B1–B15) في `01_prompt.md`.

**حقول المشهد:** `budget` (الميزانية = بداية عداد "باقي") · `goal` (هدف الشاشة مثل "1440p") · `header.label` (مثل "تجميعة 6500 ريال") · `header.counter: {label:"باقي", start}` · `hook.title: {main, desc, desc_at}` (أول فريم: "عندك **6500** ريال؟") · `preinstalled: []` · `camera.variant` 0–3.
**تلقائي:** الختام E15 (الشعار على الشاشة + "تيربو · تجميعات")، والمؤثرات (`auto_sfx`)، والستارة في اللقطات القريبة.

| العنصر | params | ملاحظات |
|---|---|---|
| **E01** الغرفة الأيزومترية | `goal` | أول فريم. الغرفة تتركب بنطّات وتطفو |
| **E02** الهدف على الشاشة | `goal` | الرقم يكبر بنطّة على الشاشة |
| **E03** لفّة الكاميرا للأمام | — | 1.25ث لين تواجه الكيس. **ضعه عند أول كلام عن القطع** (منه تبدأ أشباح القطع) |
| **E04** الكيس وأماكن القطع | `part` (cpu/cooler/mobo/ram/ssd/gpu/psu) · `category` · `name` (كما في الكابشن) · `drop_at` (كلمة الاسم) · اختياري: `price`, `price_at`, `desc`, `desc_at` | العنوان: شارة التصنيف + الاسم (Inter). القطعة تنزل 0.5ث وتثبت بومضة، وشبحها يختفي |
| **E05** السعر والميزانية | `price` · `desc` · `desc_at` | حبة السعر تحت الاسم + وسم "−السعر" داخل الكيس + العداد ينزل 0.6ث. **ابدأه مع كلمة السعر** |
| **E06** تثبيت قطعة | `part` | ومضة إضافية (الهبوط فيه ومضة تلقائياً) |
| **E07** القطعة الرئيسية | `part:"gpu"` · `category` · `name` · `price` · `price_at` · `desc` ("قلب التجميعة") | أكبر حصة من الميزانية |
| **E08** بيانات على الشاشة | `title` · `bars:[{label, value, unit}]` | الكاميرا تنزلق للشاشة (0.85ث). عمودين "بدون / مع" |
| **E09** الرجوع للكيس | — | انزلاق 0.85ث بعد E08 |
| **E10** قطعة تدخل من الجنب | `part:"psu"` · `category` · `name` · `price` · `drop_at` | تنزل قدام الكيس ثم تنزلق لمكانها |
| **E11** الكيس يكتمل | `category:"الكيس"` · `name` · `price` · `desc` | الزجاج ينزلق، الكاميرا تميل، المراوح تنور |
| **E12** المجموع | اختياري `items:[{name, price}]` · `total` · `title` | افتراضياً القائمة من كل الأسعار. العنوان "المجموع X ريال" |
| **E13** الأداء | `res` · `fps` (رقم) · `plus` · `chips:["DLSS ✓","إعدادات عالية · تقريبي"]` · `title` · `desc` | **"تقريبي" إلزامي** لو الرقم مو من اختبار منشور بنفس القطع |
| **E14** دعوة للتعليق | `title` ("وش الميزانية الجاية؟") · `desc` ("اكتبها بالتعليقات") | |
| **E15** الختام | — | تلقائي عند `closing.start` |
| **T** عنوان فقط | `chip`, `main`, `en`, `size:"mid"`, `price`, `price_at`, `desc`, `desc_at` | أي نص على منطقة العنوان |

**تمييز النص:** `**كلمة**` = أزرق الشعار، `!!كلمة!!` = أحمر (تحذير/تجاوز)، `++كلمة++` = أخضر.
**قواعد الحزمة:** تغيير بصري كل 2–4ث، ولا تكرر نفس العنصر أكثر من مرتين ورا بعض. كل رقم أو سعر ينذكر يظهر في نفس اللحظة.
