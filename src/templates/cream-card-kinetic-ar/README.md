# كرت كريمي وكلمات متتابعة — Cream Card Kinetic

قالب Remotion عمودي (1080×1920 @ 30fps) للمحتوى العربي القصير. القالب مُعامَل بالكامل: كل لون ونص ومقاس وتوقيت يأتي من `props`، ولا توجد قيمة واحدة مكتوبة داخل الكود.

---

## 1. التركيب والتشغيل

```bash
npm i remotion @remotion/cli @remotion/zod-types @remotion/media-utils @remotion/google-fonts zod
```

ضع الملفات في `src/` وسجّل `RemotionRoot` في `src/index.ts`:

```ts
import { registerRoot } from "remotion";
import { RemotionRoot } from "./Root";
registerRoot(RemotionRoot);
```

ثم `npx remotion studio`.

الأصول (فيديو، شعار، صوت) توضع في مجلد `public/` ويُشار لها بمسار نسبي مثل `"clips/shirt.mp4"` — القالب يمرّرها عبر `staticFile()` تلقائياً.

## 2. خريطة الطبقات

من الخلف إلى الأمام:

| # | الطبقة | الوظيفة |
|---|--------|---------|
| 1 | `AbsoluteFill` بلون `backgroundColor` | الخلفية الكريمية، ثابتة طوال الفيديو ولا تتحرك أبداً |
| 2 | لوحة التصميم 1080×1920 | حاوية مُحجَّمة بـ `scale(min(w/1080, h/1920))` — كل الإحداثيات بداخلها بوحدات اللوحة، فتتكيّف مع أي مقاس تركيبة |
| 3 | `<Sequence>` لكل مشهد | مشهد واحد ظاهر في كل لحظة: كرت المقطع / كلمات متراكمة / كرت ملوّن / كلمة مظللة |
| 4 | كرت المقطع | `<Video>` أو `<Img>` داخل حاوية بحواف دائرية وظل خفيف، بلا أي حركة — ثباته هو ما يعطي القالب هدوءه |
| 5 | طبقة الكابشن | تُرسم فوق الكرت (`above`) أو داخله بلون أبيض (`inside`)، ويُختار سطرها حسب الفريم الحالي من مصفوفة `captions` |
| 6 | الشعار | `<Img>` اختياري أسفل المنتصف بشفافية 0.85 |
| 7 | `<Audio>` | التعليق الصوتي، مركّب على مستوى الجذر خارج المشاهد |

| المشهد | النوع | من | إلى | الحركة |
|--------|------|-----|-----|--------|
| 1 | `mediaCaption` / `above` | 0 | 132 | الكرت ثابت. السطر يبدأ بلون `mutedFontColor` ويدفأ إلى `fontColor` خلال 13.5 فريم (0.45 ث). الكلمات تظهر تباعاً، كل كلمة `opacity 0→1` و `translateY 6→0` خلال 5 فريمات، والكلمة النشطة وزنها 900 وتحتها خط ذهبي يمسح `scaleX 0→1` من اليمين خلال 7 فريمات |
| 2 | `wordStack` | 132 | 186 | كل كلمة تدخل بـ `spring` (`damping: 200`, `mass: 0.6`) من `translateY 26→0`. الكلمة الأحدث بلون `fontColor` والسابقة ترتد إلى `mutedFontColor`. التوزيع على 70% من المشهد ليبقى وقت قراءة |
| 3 | `mediaCaption` / `inside` | 186 | 300 | نفس منطق الكابشن لكن بلون `captionInsideColor` ووزن 800 وظل نصي، داخل حدود الكرت وبلا خط ذهبي |
| 4 | `mediaCaption` / `above` | 300 | 402 | مطابق للمشهد 1 |
| 5 | `colorCard` | 402 | 480 | الكرت الملوّن يدخل بـ `spring` (`damping: 200`, `mass: 0.7`) بإزاحة 140px حسب `colorCardEnterFrom`، مع نسختين شبحيتين من النص خلفه بإزاحة 96px و192px وشفافية 0.5 و0.32 تتلاشيان خلال 15 فريم — هذا هو **أثر الحركة (echo trail)** وأبرز لقطة في القالب |
| 6 | `highlightWord` | 480 | 546 | الكلمات تظهر تباعاً على 45% من المشهد، والكلمة رقم `highlightIndex` يفتح خلفها مربع ذهبي `scaleX 0→1` من اليمين خلال 8 فريمات ولون نصها يصير لون الخلفية |

كل هذه الأرقام تُضرب في `motionSpeed` (1 = التوقيت الأصلي، 1.5 = أسرع بمقدار النصف).

## 4. الثابت مقابل المتغيّر

### هوية القالب — لا تُغيَّر

- خلفية واحدة ثابتة بلا حركة ولا تدرّج ولا نسيج.
- كرت المقطع لا يتحرك ولا يتقرّب ولا يميل — أبداً.
- الكابشن يظهر **كلمة كلمة**، لا سطراً كاملاً دفعة واحدة.
- الكلمة النشطة تتميّز بالوزن + الخط الذهبي، لا بتكبير الحجم ولا بتغيير الخط.
- السطر يدفأ من الخافت إلى الداكن، لا يظهر داكناً من أول فريم.
- مشاهد النص خالية تماماً: لا كرت ولا شعار ولا زخرفة معها.
- أثر الحركة خلف الكرت الملوّن نسختان فقط، لا أكثر.
- كل الحركات تتم بـ `interpolate` و `spring` — لا CSS animations ولا `setTimeout`.

### مفتوح للتعديل عبر props

النصوص كلها، الألوان الثمانية، الشعار، الوسائط، الصوت، الكابشن، مقاسات الكرت والخطوط، `motionSpeed`، `colorCardEnterFrom`، `trailIntensity`، `captionUnderline`، `wordRevealShare`، وترتيب المشاهد ومددها بالكامل عبر `scenes`.

## 5. حدود المحتوى

| العنصر | الحد الأقصى | السلوك عند التجاوز |
|--------|-------------|--------------------|
| `headline` | 48 حرفاً / 4 كلمات موصى بها | الكلمات تتكدس عمودياً وقد تتجاوز الشاشة بعد 5 أسطر |
| `subheadline` | 60 حرفاً | يلتف داخل الكرت الملوّن |
| `captions[].text` | 70 حرفاً / حتى 8 كلمات | يلتف على سطرين داخل عرض 900px |
| نص `highlightWord` | 40 حرفاً / 3 كلمات | الكلمات في صف أفقي واحد وتضيق المسافات |
| مدة السطر الواحد | 1.2–4 ثوانٍ | أقل من 0.8 ث لا يكفي لظهور الكلمات |

**نسبة الوسائط:** الكرت 863×1493 أي **≈ 9:15.6**. الأنسب مقاطع عمودية 9:16 مع `mediaFit: "cover"`. مقطع أفقي 16:9 سيُقص بشدة — استخدم `contain` عندها، وسيظهر لون `cardPlaceholderColor` في الفراغ.

**نسبة التركيبة:** مصمم لـ 9:16. يعمل على أي مقاس (اللوحة تُحجَّم تلقائياً)، لكن على 1:1 أو 16:9 ستظهر هوامش بلون الخلفية أعلى وأسفل اللوحة المُحجَّمة.

## 7. تحويل SRT إلى `captions`

التحويل يتم **خارج** القالب. مثال بسيط:

```ts
import { parseSrt } from "./srt"; // أو @remotion/captions

const captions = parseSrt(srtText).map((cue) => ({
  text: cue.text,
  startMs: cue.startMs,
  endMs: cue.endMs,
}));
```

ثم مرّرها في `defaultProps` أو عبر `--props`. القالب يختار السطر بـ:

```ts
const currentMs = (frame / fps) * 1000;
const cue = captions.find((c) => currentMs >= c.startMs && currentMs < c.endMs);
```

القالب يعمل بشكل سليم مع `captions: []` وبدون `voiceover` — تبقى المشاهد والنصوص كما هي.

## ملحق: ما تغيّر عند إدخال القالب في هذا المشروع

| الأمر | الأصل | هنا | السبب |
|---|---|---|---|
| الخط | Tajawal من `@remotion/google-fonts` | خط ثمانية المشترك (`lib/fonts.js`) | كل قوالب المعرض تشترك في ملفَّي خط داخل `public/fonts`؛ عائلة ثانية تعني تحميلاً إضافياً وخطاً غريباً عن بقية القوالب. الوزن 800 في الأصل صار 900 لأنه الأقرب المتاح |
| الفيديو | `<Video>` من `remotion` و `objectFit` داخل `style` | `<Video>` من `lib/media.js` و `objectFit` خاصيةً | `@remotion/media` يتجاهل `objectFit` في `style` |
| المسارات | `resolveSrc` محلية | `resolveAsset` المشتركة | تتكفّل بـ `blob:` الذي تنتجه الواجهة عند الرفع، وبخريطة أصول نسخة الملف الواحد |
| كتم الصوت | `muteMedia` | `mediaMuted` | اسم موحّد عبر المنصة كلها، ويظهر في قسم «الوسائط والشعار» |
| توقيت الكلمة | موزَّع دائماً على `wordRevealShare` | `wordStartsMs` الاختياري يُقدَّم عليه | محرّر الكلمات يكتب توقيتاً صريحاً لكل كلمة، والنقرات تتبع نفس الجدول فلا يفترق الصوت عن الصورة |
| النقرات | غير موجودة | `clickSfx` / `clickVolume` | مثل بقية قوالب المعرض |
| الأصول الفارغة | `undefined` فقط | `null` أيضاً | الواجهة تكتب `null` عند مسح أصل، وكان ذلك يُسقط الرندر بـ `Cannot read properties of null` |
