# الكرت الورقي — السطر الزاحف

قالب Remotion لفيديو عمودي قصير. جملة عربية ضخمة تزحف داخل كرت ورقي بمحطة وقوف
لكل كلمة، ثم تُقطع، ويُبنى بعدها سطر صغير كلمة كلمة.

---

## ١. خريطة الطبقات

من الخلف إلى الأمام:

| # | الطبقة | الوظيفة |
|---|---|---|
| ١ | لون الخلفية `backgroundColor` | القاعدة الداكنة |
| ٢ | نسيج الخشب `showTexture` | عروق خشنة عبر `feTurbulence` ببذرة ثابتة، مزج `overlay` |
| ٣ | فينييت `vignetteStrength` | تعتيم دائري للأطراف يدفع العين للمركز |
| ٤ | **الكرت** | مستطيل بزوايا دائرية + ظل. كل ما بعده ابنٌ له و`overflow: hidden` |
| ٤أ | وسائط المستخدم `media` | صورة أو فيديو يملأ الكرت خلف النص |
| ٤ب | حبيبات الورق | نفس فلتر الضجيج بقوة أقل، يمنع اللون المسطّح |
| ٤ج | الشعار `logo` | أعلى الكرت، بعرض ٢٢٪ منه. يختفي تماماً إن لم يُمرَّر |
| ٤د | السطر الضخم | كلمات موضوعة يدوياً + إزاحة أفقية واحدة + فلتر بلور |
| ٤هـ | السطر الصغير | كلمات تظهر تباعاً، الحافة القائدة ثابتة |
| ٤و | الكابشن | أسفل الكرت، يُختار حسب الفريم الحالي |
| ٥ | الصوت `voiceover` | `<Audio>` خارج الكرت |

الكرت كله يخضع لانسياب بطيء: دوران `cardDriftRotation`، تكبير `cardDriftScale`،
وانزياح أفقي `cardDriftX` — كلها موزّعة من نصف القيمة السالبة إلى نصف الموجبة
على طول اللقطة، فالمنتصف الزمني هو الوضع المحايد.

## ٢. جدول التايم لاين

بالقيم الافتراضية: ٣٠ إطاراً/ث، ٦١ فريم (٢.٠٣ ثانية)، جملة من ٣ كلمات.

| الفريم | الثانية | ما يحدث | شكل الحركة |
|---|---|---|---|
| ٠ – ٦ | ٠.٠٠ – ٠.٢٠ | الكلمة ١ ثابتة عند حافة الكرت القائدة | سكون تام — لا دخول ولا fade |
| ٦ – ١٠ | ٠.٢٠ – ٠.٣٣ | نقلة إلى المحطة ٢ | `easeOutQuart` + بلور أفقي |
| ١٠ – ١٧ | ٠.٣٣ – ٠.٥٧ | وقفة على الكلمة ٢ | سكون |
| ١٧ – ٢١ | ٠.٥٧ – ٠.٧٠ | نقلة إلى المحطة ٣ | `easeOutQuart` + بلور |
| ٢١ – ٣٥ | ٠.٧٠ – ١.١٧ | الوقفة الأخيرة، الأطول | سكون |
| ٣٥ | ١.١٧ | اختفاء السطر الضخم | **قطع نظيف** — بلا بلور خروج |
| ٣٥ – ٣٩ | ١.١٧ – ١.٣٠ | الكرت فارغ | صمت بصري مقصود |
| ٣٩ | ١.٣٠ | ظهور «الكلمة ١» من السطر الصغير | fade على فريمين |
| ٤٢ | ١.٤٠ | ظهور الكلمة ٢ | fade على فريمين |
| ٤٥ | ١.٥٠ | ظهور الكلمة ٣ | fade على فريمين |
| ٤٥ – ٦٠ | ١.٥٠ – ٢.٠٣ | ثبات | سكون |

**البلور مشتق من السرعة، غير مكتوب يدوياً.** تُقاس الإزاحة عند
`frame ± 0.5`، والفرق بينهما يُضرب في `motionBlurAmount` ويصير
`stdDeviation` أفقياً في `feGaussianBlur`. أفقي فقط لأن الحركة أفقية بحتة —
بلور دائري يجعل الحروف تبدو خارج التركيز بدل أن تبدو مسرعة.

## ٣. الثابت مقابل المتغيّر

**هوية القالب — لا تُغيَّر:**

- بنية المشهد: كرت ورقي مقصوص داخل خلفية داكنة.
- منطق الوقوف والنقل: محطة لكل كلمة، والسطر أعرض من الكرت فيُقصّ من الطرفين.
- البلور مشتقّ من السرعة.
- الخروج قطعٌ حاد، ثم صمت، ثم بناء كلمة كلمة.
- ثبات الحافة القائدة أثناء بناء السطر الصغير — هذا ما يجعله يبدو كأنه يُكتب.
- انسياب الكرت البطيء.

**مفتوح للتعديل عبر props:** كل الألوان، النصوص، الشعار، الوسائط، الصوت،
الكابشن، نسب الكرت، أحجام الخطوط ومواضعها، توقيت كل نقلة، شدة البلور، اتجاه
الزحف، الضجيج، الفينييت.

**نقطة انتباه:** `headlineStopFrames` يجب أن يساوي طولها عدد الكلمات ناقص واحد.
إن اختلّ العدد يوزّع القالب النقلات بالتساوي تلقائياً — يعمل، لكن الإيقاع يفقد
ارتباطه بالنطق.

## ٤. حدود المحتوى

| العنصر | الحد | ماذا يحدث عند التجاوز |
|---|---|---|
| `headline` | ٢–٤ كلمات، ≤ ٢٨ حرفاً | أكثر من ٤ كلمات يطيل اللقطة ويكسر التزامن مع الصوت |
| `subheadline` | ٢–٤ كلمات، ≤ ٢٨ حرفاً | السطر يتجاوز عرض الكرت ويُقصّ |
| `captions` | ≤ ٦٠ حرفاً للمقطع | يلتف على سطرين ثم يخرج من الكرت |
| `logo` | PNG شفاف، نسبة عرضية | يُقاس على ٢٢٪ من عرض الكرت، والارتفاع تلقائي |
| `media` | **٩:١٦** | `objectFit: cover` — أي نسبة أخرى تُقصّ من الجوانب |
| `voiceover` | m4a / mp3 / wav | المدة تُشتقّ منه وتتجاوز `fallbackDurationInFrames` |

القالب يعمل بلا صوت وبلا كابشن وبلا وسائط وبلا شعار — تظهر عندها اللقطة النصية
الصافية.

## ٥. الأصول المطلوبة

ضعها في `public/`:

```
public/
  fonts/
    thmanyah-serif-display-Black.woff2    الوزن 900 — السطر الضخم
    thmanyah-serif-display-Medium.woff2   الوزن 500 — السطر الصغير والكابشن
```

**عائلة واحدة بوزنين، لا عائلتان.** الملفان يحملان نفس العائلة الطباعية
`thmanyah serif display` (‏`nameID 16`) ويختلفان في `usWeightClass` فقط:
‏900 و 500. لذلك يُسجَّلان تحت اسم عائلة واحد بوزنين مختلفين، والتفريق بينهما
عبر `fontWeight` لا عبر اسم العائلة.

**خط ثمانية** — ملكية شركة ثمانية، متاح للاستخدام الشخصي والتجاري من المصدر
الرسمي `font.thmanyah.com`. راجع رخصته قبل الاستخدام التجاري، ولا تعِد استضافة
الملفات علناً. لا يوجد على Google Fonts، لذلك يُحمَّل محلياً عبر `FontFace` +
`staticFile()` — صفر طلبات شبكة وقت الرندر.

لا يُستخدم `loadFont` من `@remotion/fonts` هنا عن قصد: عند فشل التحميل يستدعي
`cancelRender` داخلياً فيُجهض الرندر كله بلا رجعة، ولا ينفع معه أي `catch` خارجي.
التحميل عبر `FontFace` مباشرة يجعل الفشل قابلاً للالتقاط، فيسقط القالب على مكدّس
خط عربي بديل مع تحذير في السجل بدل أن يموت الرندر.

لا يحتاج القالب صوراً ولا أشكالاً: عروق الخشب وحبيبات الورق مولَّدة عبر
`feTurbulence` ببذرة ثابتة، فالمخرج متطابق في كل رندر.

**الحزم:**

| الحزمة | السبب |
|---|---|
| `@remotion/zod-types` | `zColor()` لمنتقي الألوان في الواجهة |
| `@remotion/layout-utils` | `measureText` لقياس كل كلمة — لا بديل عنه لتثبيت الحافة القائدة |
| `@remotion/media-utils` | `getAudioDurationInSeconds` داخل `calculateMetadata` |

كلها حزم Remotion رسمية خفيفة. لا مكتبات حركة خارجية.

## ٦. التركيب

```tsx
import { Composition } from "remotion";
import { Template, calculateTemplateMetadata } from "./Template";
import { templateSchema, defaultProps } from "./schema";

export const RemotionRoot: React.FC = () => (
  <Composition
    id="paper-card-kinetic-line"
    component={Template}
    schema={templateSchema}
    defaultProps={defaultProps}
    calculateMetadata={calculateTemplateMetadata}
    durationInFrames={61}
    fps={30}
    width={1080}
    height={1920}
  />
);
```

تحويل SRT إلى `captions` يتم خارج القالب، والنتيجة مصفوفة
`{ text, startMs, endMs }`.
