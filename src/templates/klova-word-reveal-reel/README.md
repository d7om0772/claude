# قالب ريل كلوفا — كشف الكلمات

قالب Remotion لإعلان عمودي قصير (1080×1920، 30 فريم/ث). كل شيء فيه يُعدَّل عبر
props من `schema.ts` — ما فيه ولا قيمة مكتوبة داخل الكود.

---

## ١. خريطة الطبقات

الترتيب من الخلف للأمام:

| # | الطبقة | المصدر | الوظيفة |
|---|--------|--------|---------|
| 0 | خلفية اللوحة | `backgroundColor` | البيج اللي يملأ الشاشة كاملة. ثابت طول الفيديو |
| 1 | بطاقة الوسائط | `scenes[].media` أو `media` | صورة/فيديو بعرض `cardWidthPx` وحواف `cardRadiusPx`، متمركزة أفقياً وعمودياً. الارتفاع يُشتق من `aspect` |
| 1ب | البطاقة النائبة | `placeholderLabel` | تظهر بدل الوسائط لما ما يكون فيه ملف — إطار داكن بحدود نحاسية وأيقونة تشغيل |
| 2 | الشعار | `logo` | صورة مثبّتة أعلى منتصف الشاشة. ما يتحرك ولا يختفي |
| 3 | الكابشن | `captions[]` | ثلاثة أنماط، تُرسم فوق كل شيء |
| 3ب | النص الاحتياطي | `headline` + `subheadline` | يظهر فقط لما تكون `captions` فاضية |
| 4 | الصوت | `voiceover` + `clickSfx` | التعليق الصوتي، ونقرة مستقلة عند كل كلمة |

كل الرسم يتم داخل لوحة 1080×1920 ثابتة ثم تُحجَّم بـ `transform: scale()` حسب
`useVideoConfig()`. معناها كل القياسات في الكود بوحدة "بكسل التصميم" وتشتغل
صح على أي مقاس فيديو تختاره.

## ٣. الثابت مقابل المتغيّر

### ثابت — هوية القالب، لا تغيّره

- **رصف الكلمات في مواضعها النهائية.** الجملة تُحسب كاملة من أول فريم، والكلمات
  غير الظاهرة تُخفى بالشفافية بدل ما تُحذف. يعني ما فيه إعادة توسيط ولا قفز
  عند ظهور كل كلمة. هذا أهم شيء في القالب.
- **الكلمة النشطة الوحيدة.** آخر كلمة ظهرت تاخذ `fontColor`، والكل قبلها
  يخف إلى `mutedFontColor`. مو كل الكلمات الظاهرة نشطة.
- **تقسيم الجملة لمجموعات.** كل `caption` مجموعة قائمة بذاتها تُكمل ثم تختفي
  وتستبدلها التالية. المجموعة سطرين كحد أقصى.
- **محور المحاذاة اليمنى عند x=911** لنمطَي `over` و `above`، والتوسيط على
  x=540 لنمط `full`.
- **بطاقة الوسائط متمركزة أفقياً وعمودياً** مع عرض ثابت وارتفاع مشتق.
- **الشعار مثبّت أعلى المنتصف** ولا يتحرك.
- **نقرة صوتية لكل كلمة** — جزء أساسي من إيقاع القالب.

### متغيّر — عدّله من الـ props

كل الألوان، النصوص، التوقيتات، الوسائط، الصوت، عرض البطاقة ونصف قطرها،
أحجام الخط الثلاثة، سرعة ظهور الكلمة وارتفاعها، وشفافيتها الابتدائية،
وعدد المشاهد وترتيبها ونسب أبعادها.

## ٤. حدود المحتوى

### النصوص

| النمط | حجم الخط | أقصى عرض سطر | أقصى طول مريح | ملاحظة |
|-------|----------|--------------|---------------|--------|
| `over` | 77px | 400–790px | ~20 حرف / 4 كلمات | يجلس داخل أعلى البطاقة؛ أطول من كذا ينزل على وجه الشخص |
| `above` | 77px | ~440px | ~24 حرف / 4 كلمات | فوق البطاقة الأفقية؛ سطرين حد أقصى وإلا لامس البطاقة |
| `full` | 89px | 620–640px | ~30 حرف / 7 كلمات | شاشة فاضية، أوسع مساحة |

- `headline` و `subheadline` محدودان بـ 48 حرف لكل واحد في الـ schema.
- `placeholderLabel` محدود بـ 28 حرف عشان يدخل داخل البطاقة.
- تجاوز `maxWidthPx` يكسر السطر تلقائياً، بس ما فيه حد يمنعك من ثلاثة سطور —
  المسؤولية عليك.

### الوسائط

| النسبة | ارتفاع البطاقة (بعرض 860) | الاستخدام في القالب الأصلي |
|--------|---------------------------|----------------------------|
| `9:16` | 1528px | لقطات المتحدث والمنتج — الأكثر استخداماً |
| `16:9` | 484px | لقطة أفقية واحدة مع كابشن `above` فوقها |
| `1:1` | 860px | مدعوم، غير مستخدم في الأصل |
| `4:5` | 1075px | مدعوم، غير مستخدم في الأصل |

الوسائط تُقصّ بـ `object-fit: cover`، فأي ملف ينفع لكن اللي نسبته قريبة من
`aspect` هو اللي ما يفقد أطرافه.

### الصوت

- `voiceover` أي صيغة يدعمها المتصفح (mp3، m4a، wav). المدة تُقرأ منه تلقائياً.
- `clickSfx` يُنصح يكون أقصر من 250 ملي ثانية عشان لا تتداخل النقرات
  مع كلمات متقاربة.

## ٦. التركيب والتشغيل

```bash
npm i remotion @remotion/cli @remotion/zod-types @remotion/fonts @remotion/media-utils zod
```

سجّل التركيبة في `src/Root.tsx`:

```tsx
import { Composition } from "remotion";
import { Template } from "./klova-reel/Template";
import { templateSchema, defaultProps, calculateMetadata } from "./klova-reel/schema";

export const RemotionRoot: React.FC = () => (
  <Composition
    id="klova-word-reveal-reel"
    component={Template}
    schema={templateSchema}
    defaultProps={defaultProps}
    calculateMetadata={calculateMetadata}
    durationInFrames={691}
    fps={30}
    width={1080}
    height={1920}
  />
);
```

ثم `npx remotion studio` للمعاينة، و `npx remotion render klova-word-reveal-reel out.mp4` للرندر.

## ٧. تحويل SRT إلى `captions`

ملف SRT يعطيك مجموعات، مو كلمات. حوّل كل بلوك لعنصر واحد:

```ts
import type { CaptionCue } from "./schema";

const toMs = (t: string): number => {
  const [h, m, rest] = t.split(":");
  const [s, ms] = rest.replace(",", ".").split(".");
  return (Number(h) * 3600 + Number(m) * 60 + Number(s)) * 1000 + Number(ms ?? 0);
};

export const srtToCaptions = (srt: string): CaptionCue[] =>
  srt
    .trim()
    .split(/\r?\n\r?\n/)
    .map((block) => {
      const lines = block.split(/\r?\n/);
      const [start, end] = lines[1].split(" --> ");
      return {
        text: lines.slice(2).join(" "),
        startMs: toMs(start),
        endMs: toMs(end),
        style: "full" as const,
        wordStartsMs: [],
        maxWidthPx: 620,
      };
    });
```

`wordStartsMs` فاضية معناها الكلمات تتوزّع بالتساوي على 85% من مدة المجموعة.
لو عندك توقيت كلمة-بكلمة (من Whisper مثلاً)، عبّي المصفوفة وبتُستخدم كما هي —
وهذا اللي يعطي التزامن الدقيق مع النقرات.

## ٨. من وين جت الأرقام

كل قياس بصري في هذا القالب مستخرج من الفيديو المرجعي، مو تقديري:

- **التوقيتات:** عدّ بكسلات النص في كل إطار من أصل 691 إطار، والقفزات المفاجئة
  هي لحظات ظهور الكلمات. للنص الأبيض فوق الفيديو استُخدم كشف حدة الحواف بدل
  السطوع لأن خلفية المقطع فيها مناطق فاتحة تشوّش القياس.
- **أحجام الخط:** قياس عرض النص المرسوم في الإطارات ومطابقته بعرض نفس النص
  في خط ثمانية — التطابق ضمن أقل من ١٪.
- **المواضع:** استخراج الصندوق المحيط بكل سطر نص وبكل بطاقة من الإطارات مباشرة.
- **الألوان:** أخذ متوسط قيم البكسل داخل حروف النص وداخل مناطق الخلفية.

## ٩. تعديلات الدمج في هذا المشروع

| الخلل | الأثر لو بقي | الإصلاح |
|---|---|---|
| `Sequence` متداخلة حول الكابشن | الـ Sequence الداخلية تبدأ عند المقطع فتصفّر ساعة `useCurrentFrame`، بينما `wordStartsMs` توقيتات مطلقة — فما كان يظهر إلا المقطع الأول ثم لا شيء بقية الفيديو | حُذفت الداخلية وصارت نافذة الظهور تُمرَّر بالميلي ثانية (`visibleFromMs` / `visibleToMs`) |
| `loadFont` من `@remotion/fonts` | يستدعي `cancelRender` داخلياً فيُسقط الرندر ولا يلتقطه `catch` خارجي | الخط من الوحدة المشتركة `src/lib/fonts.js` |
| `<Video>` و`<Audio>` من `remotion` | غير مدعومين في الرندر داخل المتصفح | من `src/lib/media.js` (‏`@remotion/media`)، و`startFrom` صارت `trimBefore` |
| المسارات تُمرَّر خاماً | ملف يرفعه المستخدم رابطه `blob:` ولا يمرّ على `staticFile` | `resolveAsset` على الشعار والوسائط والصوت والنقرة |
| `fontFamily` حقلٌ في الـ schema | الخط أصل على مستوى المشروع لا خيار قالب | حُذف الحقل ويُستعمل `FONT_STACK` |

**حدّ معروف:** `text-shadow` تحت نمط `over` لا يرسمه الرندر داخل المتصفح (يرسم
النص عبر Canvas 2D التي لا تعرف الخاصية)، فيظهر في المعاينة وفي الرندر الخادمي
ويغيب عن الرندر داخل الصفحة. الكابشن الأبيض يبقى مقروءاً فوق البطاقة الداكنة.
